# AEO Audit Pro 🚀

**Next-Gen Search Engine Optimization & Strategic Audit Tool**

AEO Audit Pro is a high-fidelity SaaS application designed to analyze website visibility for Answer Engines (Perplexity, ChatGPT, Gemini, and more). While traditional SEO focuses on blue links, AEO Audit Pro focuses on becoming the **definitive source** for AI-driven answers[cite: 1, 2].

---

## 💡 Why AEO Pulse?

Many believe that AEO is as simple as asking an AI model for feedback. However, AI models rely on deep technical signals, structured data, and authority markers that a standard prompt cannot "see"[cite: 1, 2]. 

AEO Pulse bridges the gap between raw web data and AI intelligence by performing a technical deep-dive into the signals that actually drive AI citations[cite: 1, 2].

### Key Features:
*   **Deep Technical Scraping:** Uses residential proxies to extract live HTML and metadata, bypassing bot protections to see what AI scrapers see[cite: 1, 2].
*   **Schema Architecture Audit:** Automatically detects critical schemas like `FAQ`, `HowTo`, and `Organization` that power generative AI answers[cite: 1, 2].
*   **Strategic AEO Scoring:** Provides a 1-100 performance score based on technical "answerability" and semantic relevance[cite: 1, 2].
*   **Executive .DOCX Reports:** Generate professional, client-ready audit reports with a single click[cite: 1, 2].
*   **Gemini 2.5 Powered Insights:** Utilizes state-of-the-art LLM reasoning to provide actionable tips for content improvement[cite: 1].

---

## 🛠️ Technical Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **AI Engine:** [Google Generative AI](https://ai.google.dev/) (Gemini 2.5 Flash)[cite: 1]
*   **Scraping:** [WebScraping.ai](https://webscraping.ai/) with Residential Proxies[cite: 1, 2]
*   **Parsing:** [Cheerio](https://cheerio.js.org/) for high-speed HTML analysis[cite: 1]
*   **Styling:** Tailwind CSS with a Premium Executive UI[cite: 1]
